# Roadmap and Estimation

## Estimation method
- Estimate per work package (WP-xx) as a range (min - max man-days), never a single number.
- State the assumptions behind each range (scope, reuse, availability, dependencies) and link the risks (RK-xx) that could widen it.
- Include UX, testing, specification, build, QA and deployment effort; add a contingency and say how it was set.
- Estimates come from the tech lead and delivery team, not from the assistant alone; the assistant structures and checks coherence.
